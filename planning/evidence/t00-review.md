# T00 adversarial testing and fixes

Historical snapshot. For the current repository, tracker and bootstrap acceptance state, see [18 November reassessment](session-reassessment.md).
18 November 2026. Primary Codex assistant (GPT-6); no delegated agents or independent reviewer. The owner requested another testing round, fixes and a commit after the [initial bootstrap handoff](t00-bootstrap.md).

## Findings addressed

1. **Typecheck could miss invalid Next.js layouts on a fresh checkout.** `tsc --noEmit` checked only types already present, while Next.js route validators were generated by earlier dev/build runs. Changed `npm run typecheck` to `next typegen && tsc --noEmit`. In a separate clean project copy, an intentionally invalid layout with an extra required prop passed plain TypeScript (exit 0), then failed the new command (exit 2, `TS2344` in the generated route validator). Removed the synthetic fixture before final checks. An earlier page-prop probe did not trigger Next.js's validator; the demonstrated regression is specifically layout validation, not a claim that framework types catch every invalid page signature.
2. **Generated types would create routine Git churn.** The initial untracked `next-env.d.ts` contained generated route imports that differ between development and production. It is now ignored and regenerated by typecheck/dev/build. The clean-copy check starts without it or `.next` to prove this works.
3. **Browser coverage was narrower than the acceptance claims.** The original suite checked axe on desktop and only overflow after switching to 320px. It also missed failed styles/scripts and unintended external requests. The suite now checks keyboard focus, axe, resources, same-origin GET-only requests and overflow at 320/390/768/1440px in both Chromium and WebKit. Two additional cases cover 200% text sizing and user text-spacing overrides at 320px. Failure screenshots accompany retained traces.
4. **Local editor/session images were untracked commit candidates.** Added `.nimbalyst/` to the project ignore rules. Portable planning files do not link those internal images. They remain local and are excluded from the commit with dependencies, build output, test traces and environment files other than the blank example.

## Remaining boundaries

This is T00's static English shell. Coaching, bilingual UI, request limits, safety behavior, live evaluation and native/human review remain the later packets' work. Those features were not exercised by these shell tests. Browser text enlargement/reflow checks do not replace screen-reader, physical mobile keyboard or manual browser-zoom review. CI is prepared for the eventual independent repository and has not run remotely; the workflow nested in this folder does not enable the enclosing SongRise pipeline.

The full dependency audit found [GHSA-fc5q-39xc-vjpf / CVE-2026-112366](https://github.com/advisories/GHSA-fc5q-39xc-vjpf), a picomatch regular-expression denial of service involving repeated extglob patterns. At review time the advisory lists **no patched release**, and the npm registry's latest release is 4.0.7, within the affected range. Audit reports 16 affected development packages/ancestors across ESLint, Vite and Vitest. These are development-tool findings, not 16 independent runtime vulnerabilities. The static application does not accept user-controlled glob patterns; keep lint/test tools local and use trusted repository patterns. Recheck when a patched release is published. No fabricated safe version, forced peer resolution, custom parser fork or misleading framework downgrade was introduced. This is an unresolved dependency limitation.

The compatible ESLint 9 major also emits its upstream installation deprecation warning; the bundled React/accessibility plugins declare support through that major. No peer constraints were bypassed. Test snapshots, production-source traces and a self-review are not independent safeguarding approval.
